# AGENTS.md

## Language

在本仓库内与用户交流时，一律使用简体中文。代码、命令、术语、文件名等技术内容可保留英文，但解释、说明与讨论用中文。

Always respond to the user in Simplified Chinese when working in this repository. Code, commands, terms, and file names may stay in English.

## Agent skills

### Issue tracker

Issues are tracked as local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
