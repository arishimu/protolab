event 标记与对应性查表：内容方块 + 接收复用 + 总线信道

throwaway prototype · wayfinder ticket 03 · 判定表为 ProVerif 实跑 ns-original

本版：① 消息内容装进方块、方块镶嵌在箭杆中间，箭头指向目标（信道总线 / 接收方块）；② 接收段内容 = 实际到达的词项（发送方词项），不是接收方的占位变量；③ 复用：算子输入若来自上一步接收方块，则直接复用该方块（不再重复画），算子簇挂在其下方；④ 修正算子簇与 event 的碰撞；⑤ 矩阵点击：修掉「点空白取消选中」误清选中项的 bug。

交互：依次点两支旗（第一支 = 前提、第二支 = 结论；同一支点两次 = 自反对）；矩阵点格与图上点旗双向联动。

未做：算法化的自适应间距（ticket 08，弹性实现待讨论）；本原型 y 为手写常数，已人工避开碰撞。
