# 09: 多信道视觉语法与可访问图例

**What to build:** 在单信道和多信道协议中，让读者同时分清消息身份、值身份和信道身份；颜色、序号、线型与形状协同表达，不依赖单一颜色辨识。

**Blocked by:** 04: 水平序列与局部梯子布局; 05: 消息层与两方意图配对; 06: 人工配对、广播扇出与合流; 07: 自适应间距、刚性单元与密度折叠; 08: 事件标记与批量对应性查询.

**Status:** ready-for-agent

- [ ] 各信道是在水平序列中并列的中性总线方块，用位置、序号字形和循环边框线型区分；信道不使用身份色。
- [ ] 消息身份色只用于消息柱、消息段和箭头；值身份色只用于值方块，两组 token 由视图和图例共用，超过八个身份仍有序号和线型可区分。
- [ ] 未配对端、冲突、事件、方法盒、值方块和消息柱有形状或线型辅助标识；低对比、灰度及多信道情况下仍可读出方向和身份。
- [ ] 图例解释当前画布出现的生命线、信道、消息柱、值方块、方法盒、事件旗、未配对点、颜色和线型，并显示实际使用的消息/值序号。
- [ ] 单信道退化自然，多信道样例中的跨线弧、不同信道挂轨和同信道配对可通过语义标签辨识。
- [ ] 渲染冒烟覆盖基准样例和三信道样例，断言角色/信道/消息/值/事件/图例的可访问名称与身份，不使用像素黄金图。
