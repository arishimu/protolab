# 08: 事件标记与批量对应性查询

**What to build:** 让研究者从生命线上的事件标记直接查看 ProVerif 对有序事件对的对应性判定，并在常驻可折叠矩阵中浏览全部事件对；反例仍由现有验证结果入口呈现。

**Blocked by:** 02: 值绑定与词项追踪; 03: 结构化条件与分支作用域; 04: 水平序列与局部梯子布局.

**Status:** ready-for-agent

- [ ] 每个 `event` 成为带源码 span 的可点击事件标记；前提端用填充菱形，结论端用实心圆点和斜旗，同一标记可连续点两次查询自反对应性。
- [ ] 对同一参数集合预生成全部有序 `inj-event` 对应性查询，插入待验证文本的 `process` 之前；原始 `.pv` 文本保持不变，重复查询命中缓存。
- [ ] 矩阵常驻但可折叠，任意单元可点击；旗标选择与矩阵选择双向联动，详情展示生成的 query 原文。
- [ ] 每个矩阵单元独立呈现“证明成立”“找到反例”“未证出”，选中行列不会覆盖单元自身判定；反例单元可进入现有 trace 入口。
- [ ] 查询仍按 ProVerif 的单条结果判定，保留现有验证取消、超时、完整 stdout 及原始查询结果呈现。
- [ ] 录制输出和交互测试覆盖有序对数量、插入位置、缓存、三种判定、自反查询、双向联动和 trace 入口。
