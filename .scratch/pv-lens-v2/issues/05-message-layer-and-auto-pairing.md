# 05: 消息层与两方意图配对

**What to build:** 让一条设计意图上的消息成为跨角色对象：发送段显示发送方放上信道的 wire term，接收段显示到达接收方的词项，信道连接两端；无法可靠确定的端点清楚显示为未配对。

**Blocked by:** 04: 水平序列与局部梯子布局.

**Status:** resolved

- [x] core 的统一消息配对结果包含发送端、接收端和 `自动` 来源；未配对端是独立的消息步骤，不用空接收端伪造半条消息。
- [x] 自动配对只在恰好两条角色生命线时运行；候选必须同信道、类型兼容、结构形状兼容，按接收源码顺序消费最早未使用发送端；多方自动结果为空。
- [x] 消息的发送端、信道段、接收端在视图中可作为同一身份追踪；箭头分别指向信道和接收方块，段内分别标发送 wire term 与实际到达词项。
- [x] 未配对步骤落在对应信道挂轨并有橙色开放圆点；没有配对时不画跨角色消息路径，跨越中间生命线或信道的路径仍画水平直线（ADR-0010）。
- [x] 两方、多方和多信道样例的测试覆盖类型/形状/顺序边界、配对来源、未配对状态和消息方向；渲染冒烟可按语义身份找到端点与信道。
