# 07: 自适应间距、刚性单元与密度折叠

**What to build:** 让长协议可以在统一紧凑度控制下保持可读：布局压缩单元之间的弹性空白，保留参数、算子、消息和分支内部结构；读者可折叠密集算子簇或角色细节而不丢失后续值流。

**Blocked by:** 02: 值绑定与词项追踪; 03: 结构化条件与分支作用域; 04: 水平序列与局部梯子布局; 05: 消息层与两方意图配对; 06: 人工配对、广播扇出与合流.

**Status:** resolved

- [x] 单一连续紧凑度控制驱动 `gap.unit` 的 `[18, 26]` 范围；row/group/tight 间距由它派生并有各自绝对下限，画布高度随内容和约束变化。
- [x] 参数簇、值方块、算子簇、事件、本地步骤、折叠条、分支团和消息团作为计算单元布局；参数簇、算子簇、分支团及广播/合流团内部保持刚性。
- [x] 消息端 `y` 全局唯一，本地步骤不占消息箭头；复用、人工配对、扇出/合流和不重叠等硬约束优先于等距偏好。
- [x] 约束成环或达到间距下限后仍无法满足硬约束时显示冲突标记并延长生命线，不静默重排成另一种语义；调整紧凑度不改变水平序列。
- [x] 高密度算子簇默认折叠为显示算子名和数量的一格，下方保留后续仍引用的虚线幽灵值块；悬停可查看内含算子和值。
- [x] 角色细节折叠不改变消息行距；分支团默认展开，只受自身显式折叠开关控制。
- [x] 纯布局测试覆盖刚性、最小间距、冲突、全局 `y` 唯一、折叠幽灵值块和内容驱动高度。
