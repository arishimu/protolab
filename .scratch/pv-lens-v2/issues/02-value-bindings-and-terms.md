# 02: 值绑定与词项追踪

**What to build:** 让读者在每条生命线旁追踪角色本地持有的值：参数、`new`、`in`、`let` 和 `get` 引入值身份，后续词项引用回到对应绑定；简单构造与解构在视图中有明确方向，消息层和本地值层保持分离。

**Blocked by:** 01: 叙事 IR 兼容层与基线生命线.

**Status:** resolved

- [x] 每处参数、`new`、`in`、`let`、`get` 绑定都有稳定 id；`new` 名进入后续作用域，词项中的变量引用指向绑定 id，跨角色同名绑定不合并。
- [x] 接收端把消息层词项连接到接收角色的本地绑定；发送方词项和接收方模式分别保留，不推断跨角色值等价。
- [x] 绑定显示为带值身份色的值方块；同一绑定的再次引用和等值模式复制同色方块，未绑定的内联构造只显示虚线 wire 词项芯片。
- [x] `reduc` 表头声明的函数作为析构呈现；纯构造、元组和解构使用同一方法盒形状并由方向区分，输入与输出贴近盒体。
- [x] `PvTerm.conditional`、`let` 右侧词项及事件参数能够结构化保留，无法可靠解析的词项仍保留原文与诊断。
- [x] 基准样例和合成文本的测试覆盖绑定来源、同名隔离、`new` 后续引用、构造/解构方向、等值复用和未绑定 wire 词项。
