# 10: 源码联动、诊断和视口集成

**What to build:** 让读者在完整规范叙事视图与只读源码间双向核对，并能在长图上滚动、缩放；解析降级或错误仍保留可定位的内容，原有验证核对入口继续可用。

**Blocked by:** 07: 自适应间距、刚性单元与密度折叠; 08: 事件标记与批量对应性查询; 09: 多信道视觉语法与可访问图例.

**Status:** ready-for-agent

- [ ] 点击带源码 span 的消息步骤、值、事件和诊断，可在只读源码中高亮并定位对应行列；点击源码行可反向高亮图中对应对象。
- [ ] 反向选择按端点或绑定身份区分同名对象，不把不同角色的同名绑定一起高亮。
- [ ] 降级语法以带位置的原文标注段出现；错误显示中文行列诊断，角色内与未归属诊断各出现一次，未知语法不导致空白画布。
- [ ] 视口提供 `−`、`100%`、`+` 和“适合宽度”控件，缩放范围 60%–180%、步长 10%；滚轮滚动容器，外层容器可水平和垂直滚动。
- [ ] 完整几何按内容和硬约束保留，长协议可滚动浏览，不通过压小文字或塞进视口损失内容。
- [ ] 只读源码、按查询的验证结论、反例 trace 和完整 stdout 仍可访问，`cannot be proved` 显示为“未证出”。
- [ ] 四个基准样例、三信道样例及条件/广播合成样例完成端到端冒烟；源码联动、诊断归属和缩放边界有用户可见行为测试。
