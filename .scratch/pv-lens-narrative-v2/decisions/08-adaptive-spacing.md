# 自适应纵向间距模型：计算单元 / 等间距 / 最小值

Type: grilling
Status: resolved

## Question

v2 的纵轴从「手写 y 常数」变为自动排布后，值层 / 事件 / 消息之间的**纵向间距**怎么算。

**计算单元（本票口径）**：新值方块、参数簇、算子簇、事件、其他折叠步骤。

**本轮 grilling 已锁定**（用户判定）：

- **弹性栈 + 刚性簇**：算子簇（输入方块 + 算子盒 + 输出方块）视为**整体**；簇内紧贴**永不变**，不参与压缩。
- **所有单元间距相等，且存在最小值**；到达最小值仍放不下时，**延长生命线**（整体长高），而不是压缩簇内。
- **参数簇与生命线顶部对齐**。
- **间隙最后计算**：先摆单元、再统一分配间隙——不是「三档固定值」的查表。
- **参数区（已知方块）→ 动作区**用更大的 `gap.group`。
- **复用规则**：若算子输入所需的方块正好来自上一步**接收**的方块，则**复用**该方块（不再重复画；此时发送端点不算计算单元）。
- **跨角色耦合（配对消息处）**：复用成立时，用「假想算子簇」口径——
  - 接收方算子簇**顶部** 与 发送方**上一个单元底部** 的间距，
  - 接收方算子簇**底部** 与 发送方**下一个单元（顶部）** 的间距，
  - 两者应**相等**。

**待讨论（本票未决，用户明确「后面讨论弹性的实现」）**：

- 上述「复用 + 跨角色耦合」下的**弹性实现**：行距如何由各角色栈高的最大值决定，并在压缩后回收。
- 「最小值」与「延长生命线」的触发条件与算法（何时停止压缩、何时长高）。

## Notes

- **与 [密度与折叠](04-density-folding.md) 的关系**：相邻但**独立**，互不 block。04 定「折叠什么」，本票定「不折叠时怎么排布」；两者在**压缩次序**处汇合：`gap.group → gap.row → gap.tight → 禁止动簇内 → 折叠本地步骤`。即**折叠是最后手段，不是默认手段**。
- **口径更新（来自 issue 04 的定论）**：折叠是 04 定的**默认显示状态**，**不是本票的压缩手段**。本票的压缩次序里不应把「折叠本地步骤」当作一种压缩手段；压缩到最小值仍放不下时，按正文口径**延长生命线**（整体长高）。规格里两者分开写，避免「默认折叠」与「最后手段」打架。
- **现状**：原型 `prototype/04-event-flag-lookup.html` 的所有 `y` 仍是手写常数；本票定稿后应整体替换为算法。
- 相关画法：算子簇见 [值层](02-value-layer.md)（倒置等腰梯形，短底 = 值方块宽）；信道 / 消息见 [信道拓扑](01-channel-topology.md)。
- **外部同序约束（来自 ticket 05 的人工配对）**：解算器需接受「两条不同角色的未配对步骤属于同一行」的外部**同序约束**，作为硬约束参与弹性分配；放不下时按本票口径**延长生命线**。见 ADR-0005 与 `09-manual-pairing.md`。

## Answer

**定稿（HITL，两轮 grilling，用户全部采纳推荐）**：自适应纵向间距 = **单一弹性间距 + 等距初值 + 硬约束局部插值 + 内容决定高度**。

### 1. 适配目标

- **无视口预算**：画布高度自由（沿用今天 `pv-lens/packages/web/src/narrative/layout.ts` 的内容驱动高度）。间距取**偏好值**；`gap.unit` 由一个**单一连续紧凑度参数**驱动（默认 = 偏好值，可收至最小值），不是「三档固定值查表」。
- **「延长生命线」是唯一的高度让步**：到最小间距、或硬约束顶死时**整体长高**（可滚动），**永不压缩簇内**。
- 分工：**折叠**管「显示什么」（默认显示密度，见 [密度与折叠](04-density-folding.md)），**`gap.unit`** 管「显示出来的东西之间多松」。

### 2. 自由度：一个弹性标量

| 级别 | 覆盖 | 偏好 | 绝对下限 | 派生 |
|---|---|---|---|---|
| `gap.tight` | 同一间隙内相邻单元之间 | 26 | 18 | `= gap.unit` |
| `gap.row` | 消息行与其相邻单元之间 | 44 | 34 | `= max(34, 1.7×gap.unit)` |
| `gap.group` | **参数区→动作区**边界（每角色一处，仅此一处） | 62 | 50 | `= max(50, 2.4×gap.unit)` |

- `gap.unit ∈ [18, 26]`，全图**唯一**弹性自由度。
- **压缩次序 `gap.group → gap.row → gap.tight`** 由**绝对下限的高低**实现：旋钮下降时 group 在 `unit ≤ 20.8` 触底、row 在 `≤ 20.1`、tight 在 `= 18`——先后触底，而不是三个独立自由度上的贪心搜索。
- 数值为**可调常量**；规格保留「下限高低次序」这一约束。
- 画布留白：顶部 `TOP = 110`（参数区上方），底部 `≈ 24`。

### 3. 计算单元（闭集）与固有高度

计算单元 ∈ { 参数簇, 值方块（已知 / 新 / 幽灵）, 算子簇, 事件标记, 本地步骤, 折叠条 / 芯片 }；**消息行**另算一类。高度沿用 `prototype/05-density-folding.html` 常数：值方块视觉高 16 / 占位 26、算子盒 24、事件标记 40、本地步骤 20、折叠条 30 / 芯片 26、消息行 26。

- **参数簇 = 该角色全部角色参数字块的一整块**（内部间距 26，**刚性**、不参与压缩），算**一个**单元。
- **算子簇 = (n−1) 个输入方块 + 算子盒 + m 个输出方块**（复用输入不画），簇内紧贴、**刚性**；簇内紧贴**永不变**。

### 4. 排布

- 每个间隙的单元**自上而下顶紧**；消息行固定在**间隙底部**。
- 角色栈矮于该间隙最大值时，**余量落在消息行正上方**（不摊进内部、不推到 `gap.group`）——余量贴着语义锚点出现。
- **参数簇顶部对齐**；动作区起点全图**同一条水平线** = `paramTop + max(各角色参数簇高) + gap.group`。
- 一个间隙的高度 = `max(各角色该间隙栈高) + 行高 + 相关间距`。

### 5. 复用与跨角色耦合

- **复用**：算子输入若是同角色**上一步接收**的方块，该方块不重画；算子簇作为**一个单元**落在消息行**之后**（属于下一个间隙）。
- **跨角色耦合（硬等式）**：发送方侧的等距单元边界取「**消息行 + 接收方簇底**」整体，令
  - 发送方「上一单元底 → 消息行」的间距 **=** 「接收方簇底 → 发送方下一单元顶」的间距。
- **退化**：发送方缺上一 / 下一单元时降为**单侧**；**未配对 / 多方**（无共享行）**不施加**跨角色耦合。

### 6. 求解

- **等距是初值**：先给所有间隙填同一个 `gap.unit`（同级别倍率派生），再让硬约束**局部**修正（只动受影响的那几个间隙）。
- **硬约束**：① 跨角色耦合；② 人工配对的「同 y」；③ 单元 / 簇不重叠；④ 参数区顶对齐 + 动作区同起点。硬约束**永远赢过**等距。
- **不可满足**（成环 / 互相顶死）→ **不静默乱排**，按 [人工配对](09-manual-pairing.md) 口径**显式标冲突**，该角色**延长生命线**（长高），不压簇内。

### 7. 多方与人工配对接口

- **局部梯子**下每个角色是**独立竖直栈**（同一套单元 / 间隙模型，但无共享行），全图高 = `max(各角色栈高)`。
- **人工配对**产出 `roleA.item_i` 与 `roleB.item_j` **同 y 的硬约束**；解算器靠**插余量**满足（复用同一套跨角色耦合口径），放不下即长高。吸附 / 撤销 / 冲突标记等**交互**归 [人工配对](09-manual-pairing.md)，本票只定接口。

### 8. 边界

- 紧凑度参数（`gap.unit` 及其下限 / 倍率）**作为可调常量进规格**；MVP 是否露出 UI 控件**不属本票**，归视图 UI。
- 原型 `prototype/04-event-flag-lookup.html`（手写 `y`）与 `prototype/05-density-folding.html`（临时算法）的纵向排布将整体替换为本模型；本票**不含实现**。
- 决策固化：新增 `docs/adr/0006-adaptive-vertical-spacing.md`；`CONTEXT.md` 新增词条**计算单元 / 间隙 / 弹性间距 / 跨角色耦合**。
