## Comments

2026-11-05，阶段 4 实现完成，未提交。

**core 概念库**：`CONCEPTS` 共 43 条，覆盖 8 种操作、4 种来源、4 种折叠状态、4 种查询性质、3 种判定与 20 条图例/记法。每条都有定义、协议问题、ProVerif 读法与至少一个文档/画布锚点；文案明确“标签不是安全结论”“查询成立不等于协议整体安全”。

**查询与覆盖**：`query-presentation.ts` 为每条结果生成 `protocolQuestion`、`proverifReading`、`verdictMeaning`，并从 `PvQuery.span` 与 `collectEventReferences` 解析源码/事件锚点。`summarizeCoverage` 按声明查询与已验证结果统计保密性/认证/可达性覆盖，列出未覆盖维度；没有 query 时明确不给安全性结论。`VerifyPanel` 渲染三行、锚点按钮和覆盖摘要；App 将源码锚点接回 `handleSelectLine`，事件锚点接回旗标与对应性矩阵。

**概念与导读 UI**：新增 `ConceptNote.tsx` 抽屉；图例条目、组摘要 `?` 徽标与审计面板“概念”入口共用它。新增 `sample-guides.ts` 与 `SampleGuidePanel.tsx`，四个样例各 4–5 步；装载页展示，步骤按钮定位真实 span/事件/查询。

**验收证据**：真实 Chromium（1440×1000）8 项交互检查全部通过：导读 5 步并可高亮源码；组摘要/审计概念抽屉显示定义、协议问题、ProVerif 读法与锚点；图例条目同样可打开概念；stub 验证服务返回 3 条查询，覆盖摘要显示“不等于协议整体安全”与未覆盖可达性；查询卡三行、7 个源码/事件锚点按钮可用；事件锚点选中画布旗标并联动矩阵；查询源码锚点高亮源码行。四视口（1920×1080、1440×813、1280×720、1024×768）验证面板无页面横向溢出，1024 灰度/打印复核通过。截图存于 `docs/gui-test/23-screenshots/`：`sg4-guide-1440.png`、`sg4-concept-1440.png`、`sg4-legend-concept-1440.png`、`sg4-verify-1920/1440/1280/1024.png`、`sg4-verify-1024-gray.png`、`sg4-verify-1024-print.png`。

**验证**：`pnpm -r typecheck`、`pnpm test`（56 个测试文件、509 项测试，503 通过 + 6 跳过）、`pnpm -r run build` 全部通过。

**已知边界**：概念锚点以文档标签展示，不保证应用内直接跳转文档；导读目标针对四个内置样例，本地导入文本不显示导读；查询卡只在验证运行后出现，覆盖摘要按本次结果与实际声明查询计算；自动生成查询与反例归因属于阶段 5。
