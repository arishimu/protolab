# 29: 密码操作组画布渲染

**What to build:** 在规范叙事画布上把阶段 1 派生的密码操作组渲染为可折叠的纵向单元：展开态保持基线方法盒与值方块，折叠态替换为组摘要并保留幽灵值块；提供组审计面板、用户覆盖、源码回溯与图例说明。

**Blocked by:** 28: 解析与密码操作分类基础设施。

**Status:** resolved（实现完成，阶段 2 验收待用户复核）

- [x] 折叠态把该 item 的值层链替换为组摘要；同一角色后续行上移，本角色消息端 y 跟随行距，其他角色消息 y 不变。
- [x] 展开态不额外占几何：组开关叠在方法盒 / 派生芯片角上；默认展开时方法、芯片、值方块与基线一致。
- [x] 嵌套组逐层折叠：父组展开时子组可单独折叠；父组折叠时隐藏全部子组；线上构造的子组折叠以链尾内层摘要呈现。
- [x] 折叠摘要显示种类、方向、隐藏计数、载荷 / 密钥身份；隐藏计数由组成员与子组递归计算。
- [x] 折叠后组外仍被引用的产出以同色、同序号、同图案的幽灵值块保留；幽灵块不计入隐藏计数。
- [x] 组摘要保留 `sourceSpan` 与方程 span，`data-source-offset` 可回到源码；定位不改变折叠状态。
- [x] 审计面板按组列出角色、种类、方向、来源、置信度、隐藏计数、底层构造子与源码 / 方程行；支持覆盖、重置、逐组折叠与全部折叠 / 展开。
- [x] 图例增加“密码操作组（语义折叠）”条目，与密度折叠、未识别操作说明区分；构造实线、解构虚线，文字同时写方向，灰度与打印可辨。
- [x] 新增 `ticket29-crypto-group-render.test.ts`；既有测试只增不减。

## Comments

2026-11-05，阶段 2 实现完成，未提交。

**布局**：`structured-layout.ts` 接收 `cryptoGroups` / `collapsedCryptoGroups`，按 `group.itemId` 把组挂回 item 的值层链。折叠根组时链被替换为 `group-summary` + 幽灵值单元；展开时原样返回基线链，仅给方法盒与派生芯片挂组开关。子组折叠优先替换对应派生芯片；线上构造没有内层芯片时，在链尾追加内层摘要。组摘要高度 22、槽距 24，低于被替换的值块与方法盒链；消息行、端点与水平序列不受组折叠影响。

**core 补充**：`CryptoOperationGroup` 增加 `itemId`、`nodePath`、`functor`、`termText`、`equationSpan` 与 `ghostBindingIds`。组成员按“直接输入值 + 模式等值引用 + 输出绑定”收集，遇到已识别的嵌套操作即停止（子组输入归子组），因此 hiddenCount 与画布值块数对齐（如 checksign 隐藏 6、嵌套 aenc 隐藏 7）。幽灵绑定按“本 item 之后仍被引用”计算，折叠时由布局以同色幽灵值块呈现。

**视图**：新增 `CryptoOperationGroup.tsx`（折叠摘要 + 展开态角标开关）、`GroupAuditPanel.tsx`、`crypto-group-labels.ts`；`NarrativeView.tsx` 增加组折叠状态、全部折叠 / 展开、用户覆盖与重置、定位与协议切换清理。图例与 `v2.css` 增加构造 / 解构、用户声明、低置信、嵌套与灰度冗余样式。

**验收证据**：真实 Chromium 交互检查（1440×1000、1024×800）装载握手修正版，8 项全部通过：展开态 5 个组开关与 6 条审计记录；全部折叠出现 5 个摘要、2 个幽灵值块；全部展开恢复 6 个方法盒；嵌套 sign 子组单独折叠；审计覆盖为哈希后来源变为用户声明、重置恢复方程匹配；定位不改变折叠状态；控制台无未捕获异常。另验证切换协议后摘要与用户覆盖归零，审计“定位”只高亮源码行。四视口（1920×1080、1440×813、1280×720、1024×768）折叠态均无组内文字越界与页面横向溢出；1024 视口灰度 / 打印复核通过。截图存于 `docs/gui-test/23-screenshots/`：`sg2-groups-collapsed-1920/1440/1280/1024.png`、`sg2-groups-expanded-1440.png`、`sg2-groups-nested-1440.png`、`sg2-audit-1440.png`、`sg2-groups-collapsed-1024-gray.png`、`sg2-groups-collapsed-1024-print.png`。
