# 08: 验证 UI（运行 / 结果呈现）

**What to build:** 用户对当前协议点「运行验证」：前端把当前 `.pv` 文本发给后端（02 装载的状态在此被消费），运行中有进度且可取消；结果按查询逐条展示——查询原文（回到用户书写形式，不被归一化形态迷惑）+ 判定徽标（成立 / 被证伪 / 未能证明，措辞遵循 spec 的语义纪律），被证伪时**反例 trace 原文**可展开，完整原始输出可折叠查看。五类错误的各自中文指引：解析降级 / 解析失败 / 找不到 ProVerif（含安装与路径配置说明）/ 模型自身错误（带输出定位）/ 超时 / 服务不可达。

**Blocked by:** 02, 07

**Status:** ready-for-agent

- [ ] NS 原版端到端：运行 → 逐条查询卡片，被证伪的那条（Lowe 攻击）可展开反例 trace 原文，成立条目标徽标正确
- [ ] 判定措辞与归一化语义一致（`is true`→成立 / `is false`→被证伪 / `cannot be proved`→未能证明，并解释不等于不成立）
- [ ] 运行中可取消；超时有提示
- [ ] 找不到 ProVerif 时给出中文安装指引与路径注入说明（ADR-0002 后果）；模型报错与解析失败各有带定位的呈现
- [ ] 界面中文，术语与代码保留英文
