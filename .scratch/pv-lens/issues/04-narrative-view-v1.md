# 04: 规范叙事视图渲染 v1（泳道图）

**What to build:** 用户装载一个协议后，浏览器把语义模型画成**规范叙事视图**：每个命名进程一条泳道，泳道内按代码顺序排列消息步骤卡片（方向箭头、所在信道、**词项符号化渲染**如 `{Na,A}pkB` 风格、事件标注、`new` 新鲜名标注、守卫注释）；不能可靠确定收发配对的步骤明确标注为**未配对步骤**（不臆造连线）；解析器的降级诊断以「原文标注卡片」形态入图；模型无角色结构时给明确提示而非白屏。画对优先于画全。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 握手修正版端到端：装载 → 渲染出 client/server 两条泳道、各自步骤、事件标注与符号化词项的正确图
- [ ] 词项符号化渲染通过黄金断言（加密/签名/元组/函数应用的惯用记法；未知构造子回退为函数调用写法）
- [ ] 未配对步骤在图上有明确视觉标注；无任何臆造连线
- [ ] 降级诊断段以原文标注卡片显示在泳道内；无角色结构的模型显示中文提示而非白屏
- [ ] 泳道图由 web 自绘（无自动布局引擎依赖），中文 UI、术语保留英文
