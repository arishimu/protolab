# 12: 意图配对引擎（类型 + 顺序，两方协议）

**What to build:** 把 `pairSteps` 从「Dolev-Yao 双向唯一」改写为「设计意图配对」，语义与判定规则见 ADR-0003：

1. 不同角色、同一信道；
2. 类型兼容（缺类型保守不匹配）；
3. 形状匹配（构造子/元组递归，裸变量受类型约束的通配）；
4. 恰好两条泳道时按接收步骤源码顺序、贪心一对一消费最早的兼容 `out`；
5. 泳道多于两条时返回空（多方路由不可静态推断）。

**Blocked by:** 11

**Status:** resolved

- [ ] 合成两方协议：类型唯一确定的 out/in 双向产出连线
- [ ] 类型不符（`aenc(...)` vs `pkX: pkey`）不连
- [ ] 顺序：同一角色多条同型 out / 同型 in 时按源码顺序配对，不交叉
- [ ] ≥3 泳道返回空集（零误配）
- [ ] 四个真实样例：两方样例产出教科书流，多方样例零边
- [ ] 结果可被 web 布局原样消费（`StepPairing` 契约不变）
