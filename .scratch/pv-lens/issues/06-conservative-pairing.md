# 06: 保守配对引擎 + 可信连线

**What to build:** core 里一个保守的纯函数：只在结构上**可确定**时把某角色的 `out` 与另一角色的 `in` 配成跨泳道连线，任何歧义一律不连、保持未配对标注。四真实样例在 Dolev-Yao 公共信道模型下很可能配不出任何边——因此本票承诺的是「机制 + 不误配的保证」，不是「图上出现大量箭头」。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 合成夹具（两个角色、信道收发结构可唯一确定配对）上能正确产出连线
- [ ] 歧义/无法确定用例产出「不连」而非猜测（零误配）
- [ ] 四真实 fixture 上：要么产出经人工核实的正确边，要么产出零边——两种情况都有对应测试断言
- [ ] 配对结果可被 04 的渲染消费（连线形态由渲染端决定，本票只产出配对判定）
