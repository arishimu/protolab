# ADR-0017: 标签盒模型与语义换行

**状态**：已接受（2026-11-03），随第二轮 R05 实施。

## 背景

事件标签在生命线外侧绘制。最左角色的事件标签向左延伸，画布没有为它预留槽位，标签因此越过 SVG 左缘，只剩后半段可见。旧渲染器按字符预算直接切片，再用空格拼接两段，使 `not attacker(Na)` 显示为 `not attacke r(Na)`，`event beginA(nA)` 可能显示为 `event begi` 与 `nA(nA)`。本地步骤与降级原文也复用了同一切片逻辑。

## 决策

1. 事件标签的放置先计算可用横向空间。最左角色按最长事件标签预留左槽位；左侧空间不足时，标签锚点翻转到标记右侧，或由左槽位承载。标签包围盒必须落在画布内容区内。
2. 事件与分支标签的断行只允许发生在空格、逗号、左括号或等号等语义边界。两行仍超预算时，第二行以省略号收束，全文保留在 `title` 与 `aria-label` 中。不得在标识符内部断行。
3. 本地步骤、`insert` 胶囊与降级原文保持单行逐字。节点宽度按原文长度扩展，必要时由 `title` 承载全文；不得因换行或拼接插入原文不存在的空格。
4. 标签背景矩形覆盖实际可见行与折叠后的行数；左右锚点由布局字段决定，渲染器不自行改变方向。
5. 标签预算分别使用下一列左缘和前一列右缘，不再对向外标签固定为 24 字符。

## 后果

- 最左角色的画布宽度可能增加，左右列间距仍由水平序列与列宽决定。
- 长事件标签可能显示为两行，标签背景与事件旗标保持分离。
- 降级与 `insert` 原文逐字可读，源码联动与 `title` 全文不再互相替代。
- 布局测试新增标签包围盒与语义断行断言；浏览器验收覆盖握手修正版最左事件、多信道事件换行与降级原文。
