# ADR-0002: ProVerif 只经 CLI 适配器调用，MVP 不打包分发

后端不内嵌、不链接 ProVerif，只通过一个 CLI 适配器 `spawn` 可执行文件来调用。proverif 可执行文件的路径可注入，并支持超时与取消。MVP 假设运行机器已自行安装 ProVerif，本机路径为 `~/.opam/default/bin/proverif`，不随应用打包分发。自带二进制与容器化留作后续独立决策，适配器已预留扩展点。

理由：ProVerif 是独立的 OCaml 工具，没有稳定的库级 API，内嵌调用不现实。它作为静态二进制分发的跨平台成本与研究许可条款尚未解决，MVP 期不值得承担。接口收窄后，更换 bundle、容器或验证后端都只改适配器一处。

被否决的选项：内嵌调用，无稳定 API；MVP 即打包分发，跨平台二进制与许可成本高，价值未验证。

后果：安装文档必须写明需要本机 ProVerif 2.x 及路径注入方式。解析与调用失败须区分找不到可执行文件与验证报错两类错误，分别呈现给用户。
