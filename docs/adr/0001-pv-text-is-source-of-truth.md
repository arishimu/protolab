# ADR-0001: `.pv` 文本是唯一真源，可视化视图是派生数据

协议模型的唯一真源是 `.pv` 文本；泳道图等一切可视化结构都是它的**派生视图**，通过「`.pv` → 解析 → 视图」的单向管线生成。二期画布编辑（增删拖拽）产生的是对文本的修改：先把改动序列化回 `.pv` 文本，再走同一条管线重绘——不引入独立的图格式作为一等存储。

理由：ProVerif 只认文本，保存、共享、验证都以 `.pv` 为单位；若视图可独立于文本存在并反向合回，必然出现双向漂移，而「所见即所验证」要求图和被执行验证的文本严格一致。

后果：不存在「图的存档文件」；未配对/降级等展示状态始终可从文本重算；未来的反向映射（图 → 文本）必须保证文本是管线终点而不是并行的第二真源。
