# ADR-0001: `.pv` 文本是唯一真源，可视化视图是派生数据

协议模型的唯一真源是 `.pv` 文本。规范叙事视图等可视化结构都是它的派生视图，由 `.pv` 文本经解析单向生成。二期画布编辑产生的是对文本的修改：先把增删与拖拽序列化回 `.pv` 文本，再走同一条管线重绘。不引入独立图格式作为一等存储。

理由：ProVerif 只接受文本，保存、共享与验证均以 `.pv` 为单位。若视图可以独立于文本存在并反向合回，两条路径必然漂移。图与被验证的文本必须严格一致。

后果：不存在图的存档文件。未配对、降级等展示状态始终可从文本重算。未来的反向映射（图到文本）必须保证文本是管线终点，而不是并行的第二真源。
