# ADR-0015: 视口布局与滚动所有权

**状态**：已接受（2026-11-02），已于 2026-11-03 随 P2 批次实施（E1/E2/D1/D2/D6）；同日随第二轮 R04 修订视口模式，2026-11-04 随第二轮 R08 修订窄屏堆叠顺序与自动适配下限。

## 背景

U1.4 要求图与源码文本可并列查看，U8.6 要求画布对象与源码行双向联动。现有实现把源码面板放在画布上方，内容列固定为 900 px；画布没有高度上限，横向滚动条落在整张 SVG 底部。点击画布对象时，源码面板对目标行调用 `scrollIntoView`，该调用滚动整个文档，页面跳回顶部，人工配对与矩阵联动因此中断。

## 决策

1. 1280 px 以上采用两列布局：源码列宽 320–420 px，画布列自适应；1280 px 以下上下堆叠。`.app` 最大宽度改为 `min(1600px, 100%)`。
2. 源码面板在宽屏下 `position: sticky`，最大高度为视口高度减 2 rem；画布容器最大高度为 75 vh 并内部滚动。横向滚动条因此位于画布容器底部，不在画布内容底部。
3. 滚动所有权分离：点击画布对象只滚动源码面板容器内部；点击源码行只滚动画布容器内部；点击矩阵单元只滚动画布容器内部。页面滚动只允许由 `revealPanel(panel)` 调整到目标面板边界，不对行或对象调用。
4. `revealPanel` 仅在目标面板完全不可见时对面板容器调用 `scrollIntoView({ block: 'nearest' })`；宽屏两栏同时可见时不产生页面滚动。
5. 首次进入时布局宽度超过容器宽度，自动执行一次适合宽度；用户手动缩放后不再自动调整。布局未超出容器时保持 100%。
6. 点击事件旗标把矩阵带入视口，不滚动源码面板；源码定位由显式的「定位源码」按钮或诊断条目触发。
7. 2026-11-03 R04 修订：保留默认 75 vh 限高与内部滚动；增加「展开画布」「全屏画布」与「适合页面」三种视口模式。展开画布取消内部限高，纵向浏览由页面滚动承担；全屏画布使用覆盖视口的固定容器，锁定页面滚动，Esc 或按钮退出；适合页面按容器宽高同时缩放，作为全图概览，允许低于手动缩放下限，并在界面标明概览状态。三种模式不改变滚动所有权：画布对象、源码行与矩阵的联动仍只滚动各自容器；展开模式下的页面滚动由用户直接发起。
8. 画布滚动容器的滚动条使用可见样式；滚动超过阈值时提供「回到顶部」，只滚动画布容器。
9. 2026-11-04 R08 修订：1280 px 以下上下堆叠时画布列在前、源码列在后，首屏直接呈现画布；宽屏两列的左右位置不变。装载页提供「隐藏源码」入口：隐藏后源码列不渲染占位，宽屏收为单列，画布占满宽度，选择经 sessionStorage 在会话内记忆。自动适配即适合宽度设最小可读缩放 90%：容器与布局之比低于该值时保持 100% 并允许横向滚动，不再压缩到 60%；手动缩放范围与适合页面概览下限不变。

## 后果

- U8.6 的滚动到对应源码行解释为源码面板内部滚动；页面滚动不再是联动副作用。
- 画布在宽屏下获得更多宽度，四角色样例的初始可见性改善；窄屏仍依赖容器滚动。
- 两栏布局压缩画布列，适合宽度成为默认入口；用户仍可手动缩放至 180% 查看细节。
- 适合页面可能缩到 12%–60%，只用于结构概览；文字阅读应使用 100% 或全屏模式，界面以「全图概览」提示说明。
- 窄屏首屏先见画布后见源码；隐藏源码是会话内的临时选择，不改变装载与联动行为。
- 自动适配不再缩到 90% 以下，超宽布局保持 100% 并依赖画布容器横向滚动，如 NS 修正版在 1024 宽时。
- 该决策不影响 `.pv` 真源、配对语义与验证流程。
