# ADR-0011: 产品分期——先交付只读阅读与验证，画布编辑归二期

**状态**：已接受（2026-10-26）

安全协议可视化建模与形式化验证是 pv-lens 的长期愿景，但 v1 与 v2 两轮规格实际交付的都是只读派生视图与 ProVerif 验证。本 ADR 把愿景拆成明确分期，消除承诺建模而交付只读的定位错位（`docs/summary.md` 风险 1）。

## 背景

- README 与多份规格把工具称为可视化建模，而实际入口与 ADR-0001 一致：`.pv` 导入、只读派生视图、本机 CLI 验证。
- 画布编辑在 v1/v2 规格中始终被排除在范围外，即增删拖拽组件并回写 `.pv`，属 v2 map 的 Out of scope。
- 2026-10-26 的风险评审给出三个选项：收窄为纯阅读工具、维持愿景并明确分期、暂停 v2 先做编辑 spike。用户选择维持建模愿景、明确分期。

## 决策

1. 分期：
   - MVP（当前）= 只读规范叙事视图 + ProVerif 验证。v1 已交付；v2 票 01–10 在此范围内迭代阅读体验。
   - 二期 = 画布编辑并回写 `.pv`，含反例与攻击视图等独立 effort；开工前另立 ADR 与规格。
2. 不改变 ADR-0001：即使二期实现，编辑结果仍写回 `.pv` 文本再重新解析与验证，文本是唯一真源。
3. 不为二期提前设计：v2 票的验收一律以读懂协议、正确呈现验证结论为准；不为可逆回写保留额外布局信息或编辑态 IR。
4. README 与对外描述按此表述：可视化建模保留为远期愿景，不作为当前能力承诺。

## 被否决的选项

- 收窄定位为纯阅读与验证工具：放弃既有愿景表述；用户选择保留建模愿景。
- 暂停 v2、先做画布编辑 spike：搁置正在完成的主线，推倒既有设计资产，在编辑价值未经评估时风险最大。

## 后果

- 承诺与交付对齐：当前产品定位为阅读与验证，建模明确挂到二期。
- 二期开工需新 ADR，覆盖编辑交互与回写语义，并重新评估 v2 视觉语言在编辑场景下的可复用性。
- `docs/summary.md` 的风险 1 由本 ADR 解决。
