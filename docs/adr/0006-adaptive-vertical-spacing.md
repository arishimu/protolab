# ADR-0006: 自适应纵向间距 = 等距初值 + 硬约束局部插值 + 单一弹性间距

**状态**：已接受（2026-09-22）

## 背景

v2 的规范叙事视图（ADR-0004）纵轴从「手写 y 常数」变为自动排布后，值层 / 事件 / 消息之间的**纵向间距**需要一个模型。原型 `.scratch/pv-lens-narrative-v2/prototype/04-event-flag-lookup.html` 全部 `y` 是手写常数；`.scratch/pv-lens-narrative-v2/prototype/05-density-folding.html`（密度与折叠票）的纵向重排只是临时算法（每间隙取各角色栈高最大值），且其正文与「折叠是默认显示密度还是压缩手段」口径冲突。本决策把间距模型与折叠模型分开定死。

## 决策

自适应纵向间距 = **单一弹性间距 + 等距初值 + 硬约束局部插值 + 内容决定高度**（定稿见 `.scratch/pv-lens-narrative-v2/decisions/08-adaptive-spacing.md`）：

1. **适配目标**：不引入视口预算，画布高度内容驱动。间距取偏好值，`gap.unit` 由**单一连续紧凑度参数**驱动（默认 = 偏好值，可收至最小值）。**永不压缩簇内**；间距到最小或硬约束顶死时**延长生命线**（整体长高、可滚动）。
2. **单一自由度**：`gap.unit` 是唯一弹性标量；`gap.row` / `gap.group` 由其倍率派生并受**绝对下限**约束。压缩次序 `gap.group → gap.row → gap.tight` 由**下限高低**实现（先后触底），而非三个独立自由度上的贪心。
3. **层级归属**：`gap.tight` 管同间隙相邻单元；`gap.row` 管消息行；`gap.group` **只**管参数区→动作区。
4. **刚性单元**：**参数簇**与**算子簇**各自是一个刚性计算单元，内部紧贴、不参与压缩。计算单元为闭集：参数簇、值方块（已知 / 新 / 幽灵）、算子簇、事件标记、本地步骤、折叠条 / 芯片；消息行另算一类。
5. **排布**：间隙内单元自上而下顶紧、消息行落在间隙底部，栈矮角色的余量落在**消息行正上方**；参数簇顶部对齐，动作区起点全图**同一条水平线**。
6. **复用与跨角色耦合**：接收方块被算子复用时，算子簇作为**一个单元**落到消息行之后（下一间隙）；发送方侧的等距单元边界取「**消息行 + 接收方簇底**」整体，令发送方上一单元到消息行的间距**等于**接收方簇底到发送方下一单元的间距——这是**硬等式**，缺一侧降为单侧，未配对 / 多方不施加。
7. **求解**：等距是**初值**，硬约束（跨角色耦合 / 人工配对同 y / 不重叠 / 顶对齐）**局部插值**且**永远赢过**等距；不可满足（成环、顶死）**显式标冲突**并长高，不静默乱排。
8. **多方 / 人工配对**：局部梯子下每个角色是独立竖直栈（无共享行），全图高 = `max(各角色栈高)`；人工配对产出**同 y 硬约束**，靠插余量满足。交互归 `.scratch/pv-lens-narrative-v2/decisions/09-manual-pairing.md`，本 ADR 只定解算器接口。

## 被否决的选项

- **视口预算驱动压缩**：今天实现（`narrative/layout.ts`）与原型都是内容驱动高度、SVG `width:100%; height:auto`，没有任何高度预算；引入预算会把「可读性下限」与「适配视口」两件事混在一起。需要时以后作可选 fit-to-viewport 开关（(b) 的扩展）。
- **三级各自独立的弹性值**（`group` / `row` / `tight` 各自带偏好与最小、各自求解）：三个自由度会让「压缩次序」变成贪心搜索，实现与解释都更贵；改为一个标量 + 倍率 + 绝对下限。
- **三档固定值查表**：间距来自内容与约束，不是查表；查表无法容纳跨角色耦合与复用。
- **压缩簇内**以实现更矮的图：会让「同一条消息的两端对齐」「输入紧贴算子盒」的语义塌掉；宁可长高。
- **把折叠当作压缩手段**：折叠是**默认显示密度**（`.scratch/pv-lens-narrative-v2/decisions/04-density-folding.md`），与间距压缩是两件事；压缩次序里不含折叠。

## 后果

- `pv-lens/packages/web/src/narrative/layout.ts` 的纵向排布将整体替换为本模型（实现 ticket 另开，本决策不含实现）。
- `CONTEXT.md` 新增**计算单元 / 间隙 / 弹性间距 / 跨角色耦合**四个词条（只写概念，数值与倍率不进词表）。
- 解算器须接受**外部同序约束**（人工配对，ADR-0005）作为硬约束，并复用跨角色耦合口径。
- 「延长生命线 / 可滚动」与视觉语法细节（缩放、滚动）的关系仍属 map 的 Not yet specified。
