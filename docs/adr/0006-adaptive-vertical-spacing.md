# ADR-0006: 自适应纵向间距 = 等距初值 + 硬约束局部插值 + 单一弹性间距

**状态**：已接受（2026-09-22）

> **修订（2026-11-02）**：ADR-0008 取消同一条消息共享 y，改为各端落在本地梯子；ADR-0013 修订第 5 点的动作区起点等式，并加入发送端先于接收端的因果约束。下文涉及消息共享 y、人工配对同 y 的表述，按这两份 ADR 解释。

## 背景

v2 的规范叙事视图（ADR-0004）纵轴从手写 y 常数变为自动排布后，值层、事件与消息之间的纵向间距需要一个模型。原型 `.scratch/pv-lens-v2/prototype/04-event-flag-lookup.html` 的 `y` 全是手写常数。`.scratch/pv-lens-v2/prototype/05-density-folding.html`（密度与折叠票）的纵向重排是临时算法，每间隙取各角色栈高的最大值，且其正文对折叠是默认显示密度还是压缩手段的表述自相冲突。本决策把间距模型与折叠模型分别确定。

## 决策

自适应纵向间距 = 单一弹性间距 + 等距初值 + 硬约束局部插值 + 内容决定高度，定稿见 `.scratch/pv-lens-v2/decisions/08-adaptive-spacing.md`：

1. 适配目标：不引入视口预算，画布高度由内容驱动。间距取偏好值，`gap.unit` 由单一连续紧凑度参数驱动，默认取偏好值，可收至最小值。簇内永不压缩。间距到最小或硬约束已到极限时延长生命线，画布整体长高并可滚动。
2. 单一自由度：`gap.unit` 是唯一弹性标量；`gap.row` / `gap.group` 由其倍率派生，并受绝对下限约束。压缩次序 `gap.group → gap.row → gap.tight` 由下限高低实现，先后触底，不是三个独立自由度上的贪心。
3. 层级归属：`gap.tight` 管同一间隙内的相邻单元；`gap.row` 管消息行；`gap.group` 只管参数区到动作区。
4. 刚性单元：参数簇与算子簇各自是一个刚性计算单元，内部紧贴，不参与压缩。计算单元是闭集：参数簇、值方块（已知 / 新 / 幽灵）、算子簇、事件标记、本地步骤、折叠条与芯片；消息行另算一类。
5. 排布：间隙内单元自上而下顶紧，消息行落在间隙底部，栈矮角色的余量落在消息行正上方。参数簇顶部对齐，动作区起点在全图同一条水平线上。
6. 复用与跨角色耦合：接收方块被算子复用时，算子簇作为一个单元落到消息行之后，即下一间隙。发送方侧的等距单元边界取消息行与接收方簇底的整体，使发送方上一单元到消息行的间距等于接收方簇底到发送方下一单元的间距。这是硬等式，缺一侧时降为单侧，未配对与多方不施加。
7. 求解：等距是初值，硬约束局部插值且永远优先于等距，硬约束包括跨角色耦合、人工配对声明的因果序、不重叠与顶对齐。约束不可满足时，如成环或约束到极限，显式标冲突并长高，不静默乱排。
8. 多方与人工配对：局部梯子下每个角色是独立竖直栈，无共享行，全图高 = `max(各角色栈高)`。人工配对产出消息因果边，各端保留本地 y，靠插余量满足顺序约束。交互归 `.scratch/pv-lens-v2/decisions/09-manual-pairing.md`，本 ADR 只定解算器接口。

## 被否决的选项

- 视口预算驱动压缩：现有实现 `narrative/layout.ts` 与原型都是内容驱动高度，SVG 为 `width:100%; height:auto`，没有高度预算。引入预算会把可读性下限与适配视口两件事混在一起。需要时可另作可选的 fit-to-viewport 开关。
- 三级各自独立的弹性值，`group` / `row` / `tight` 各带偏好与最小、各自求解：三个自由度使压缩次序变成贪心搜索，实现与解释成本都更高。改用一个标量、倍率与绝对下限。
- 三档固定值查表：间距来自内容与约束，不来自查表；查表无法容纳跨角色耦合与复用。
- 压缩簇内以得到更矮的图：会使同一条消息的两端对齐、输入紧贴算子盒这两项语义失效，宁可长高。
- 把折叠当作压缩手段：折叠是默认显示密度，见 `.scratch/pv-lens-v2/decisions/04-density-folding.md`，与间距压缩是两件事，压缩次序不含折叠。

## 后果

- `pv-lens/packages/web/src/narrative/layout.ts` 的纵向排布将整体替换为本模型。实现另开 ticket，本决策不含实现。
- `CONTEXT.md` 新增计算单元、间隙、弹性间距、跨角色耦合四个词条，只写概念，数值与倍率不进词表。
- 解算器须接受外部同序约束（人工配对，ADR-0005）作为硬约束，并复用跨角色耦合的定义。
- 延长生命线与可滚动如何配合缩放与滚动，仍属 map 的 Not yet specified。
